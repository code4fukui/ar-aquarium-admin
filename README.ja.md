# ar-aquarium-admin

[ar-aquarium](https://github.com/code4fukui/ar-aquarium) プロジェクト用の管理インターフェースです。

## デモ
URLパラメータを指定して [ar-aquarium-admin](https://code4fukui.github.io/ar-aquarium-admin/) にアクセスしてください（例: https://host/api/path1/path2/）。

## 機能
- AR水族館内の魚の追加・編集・削除が可能
- 魚の行動や外観をカスタマイズするオプションを提供
- 魚データを [json-storage](https://github.com/code4fukui/json-storage/) バックエンドに保存

## 必要条件
- [json-storage](https://github.com/code4fukui/json-storage/) バックエンドのセットアップ

## 使い方
1. [json-storage](https://github.com/code4fukui/json-storage/) バックエンドをセットアップします。
2. URLパラメータを指定して [ar-aquarium-admin](https://code4fukui.github.io/ar-aquarium-admin/) にアクセスします（例: https://host/api/path1/path2/）。
